## 📖 About The Project

<div align="center">

**Frostguard** is a **free** and **open-source** automation assistant for daily tasks, multi-account management, and Whiteout Survival progression. No paywalls, ever.

</div>

> [!NOTE]
> **Acknowledgment:** Frostguard is actively maintained with continued feature work and reliability improvements.

## 🛠️ Installation & Setup

Choose the path that matches what you want to do:

| Path | What it provides | Update model |
|:-----|:-----------------|:-------------|
| **Stable** | A tested, versioned release | Changes only when a new Stable is published |
| **Nightly** | The latest development state; may be unstable | Rebuilt daily from `main` |
| **PR build** | A temporary build containing selected open pull requests | Expires automatically |
| **Source build** | A local Maven build from the repository | Built on demand from the checked-out commit |

### ⬇️ Install Frostguard on Windows

Stable and Nightly use separate, self-contained Windows applications. Git,
Maven, and a separately installed Java runtime are not required.

- **[Latest Stable release](https://github.com/Shederator/wosbot/releases/latest)**
- **[Nightly releases](https://github.com/Shederator/wosbot/releases)**

After choosing a build:

1. Download the Windows x64 MSI for the desired channel.
2. Confirm the download is from the official `Shederator/wosbot` release and
   run the installer. A Windows **Unknown publisher** warning is currently
   expected.
3. Start **Frostguard** or **Frostguard Nightly** from its shortcut.
4. Open **Configuration** and select your emulator's command-line controller.

> [!IMPORTANT]
> Stable and Nightly keep separate settings and databases and can run side by
> side. The first Nightly start can copy a one-time Stable snapshot; changes are
> not synchronized afterward.

See the **[complete installation guide](docs/installation.md)** for emulator,
game, and source-development settings.

### 🧪 Test pull requests

Request a temporary build of one or more open pull requests with `/build-pr` in
the Discord `#request-a-build` channel.

PR builds remain temporary ZIP bundles rather than installed release-channel
products. They contain unmerged code and expire automatically.

### 🛠️ Build from source

Developers need Java 21, Git and Git LFS. The Maven Wrapper supplies Maven:

```sh
git clone https://github.com/Shederator/wosbot.git
cd wosbot
git lfs install
git lfs pull
./mvnw package
./mvnw javafx:run
```

The first command builds and tests Frostguard; the second starts the desktop
application directly from the reactor. The transitional Windows desktop bundle
is written below `packaging/desktop/target`. For the complete source setup and
verification commands, see:

- **[Installation and source build](docs/installation.md)**
- **[Windows-specific setup](docs/windows.md)**
- **[CI and bundle verification](build-support/verification/README.md)**

### Emulator Executable Paths

When prompted by the bot launcher, select the **command-line controller** (not the graphical app):

<details>
<summary><b>📂 MuMu Player</b></summary>

```
C:\Program Files\Netease\MuMuPlayerGlobal-12.0\shell\MuMuManager.exe
C:\Program Files\Netease\MuMuPlayer\nx_main\MuMuManager.exe
```
</details>

<details>
<summary><b>📂 MEmu</b></summary>

```
C:\Program Files\Microvirt\MEmu\memuc.exe
```
</details>

<details>
<summary><b>📂 LDPlayer 9</b></summary>

```
C:\LDPlayer\LDPlayer9\ldconsole.exe
```

> [!WARNING]
> You must manually enable ADB: `Settings → Other settings → ADB debugging → Enable local connection`
</details>

### Required Instance Settings

<div align="center">

| Setting | Value | Status |
|:-------:|:-----:|:------:|
| **Resolution** | `720 × 1280` (Portrait) | 🔴 **Mandatory** |
| **DPI** | `320` | 🔴 **Mandatory** |
| **Language** | English | 🔴 **Mandatory** |
| **CPU / RAM** | 2 Cores / 2 GB | 🟡 Recommended |

</div>

> [!TIP]
> In the game's settings, disable *Snowfall* and *Day/Night Cycle*, and avoid *Ultra* graphics. This considerably improves performance and visual reliability for the bot.
