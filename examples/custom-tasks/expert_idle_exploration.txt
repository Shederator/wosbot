Title: Handle Trek Supplies with idle exploration
Status: Editable Task Builder example.
When: Run only after validating the destination, OCR region, and tap areas on your account.

How to test:
1. Stop the normal task queue after initialization.
2. Open Task Builder and import expert_idle_exploration.json.
3. Check the End Idle and start-idle branches on the relevant game screens.
4. Save and re-import the JSON to verify the flow and its connections.

Flow:
- From World, open Trek Supplies through Sidebar Navigation and wait for the screen.
- Read the configured region for the End Idle action.
- If End Idle is present, tap it, wait briefly, then exit the screen.
- Otherwise, open the bag preview, wait for its animation, select Idle, and confirm the quantity.
- After confirmation, wait briefly and press Back twice to return to World if the empty bag remains open. Both Back actions run even when the game has already returned to World.
